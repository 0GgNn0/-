# LinkTree 前端页面布局优化计划

## 概述

对 LinkTree 全部 4 个前端页面（首页、管理后台、登录页、AI 对话页）进行布局结构重构、响应式改进、视觉风格升级和交互体验增强。先生成 UI 原型图，再逐步实施。

---

## 当前状态分析

### 现有页面问题

**index.html（公开首页）**
- 主卡片 + 右侧小组件的 flex 并排布局在中等屏幕下体验不佳（600-900px 区间小组件被挤到下方但布局切换生硬）
- 作品展示区 2 列网格在卡片数量少时显得空旷
- 文件下载区与作品区视觉区分不够明显
- 小组件（时钟/日历/天气）与主内容区关联弱，右侧浮动定位不够稳定
- 底部 footer 的"聊"/"管"按钮位置固定在右上角，不够直观

**admin.html（管理后台）**
- Tab 导航在移动端 5 个 tab 过于拥挤
- 链接编辑使用 `prompt()` 弹窗，体验原始
- 表格在移动端显示不全（已隐藏 URL 列但仍不够）
- 作品管理卡片网格和文件管理表格风格不统一
- 设置页表单过长，缺少分组卡片

**login.html（登录页）**
- 页面过于简单，缺少品牌元素和视觉层次
- 无动态背景效果

**chat.html（AI 对话页）**
- 侧边栏在移动端体验可优化
- 欢迎页过于简单
- 消息区缺少时间戳显示
- 模型选择器位置不够显眼

## 实施计划

### 步骤 1: 生成 UI 原型页面

创建一个独立的 HTML 原型文件 `prototype.html`，包含所有 4 个页面的可视化原型，使用真实的 CSS 样式，可以在浏览器中直接预览。

**文件**: `templates/prototype.html`（新建）

原型将包含：
- 4 个页面的完整布局原型（通过 Tab 切换查看）
- 使用项目现有的 CSS 变量体系
- 亮色/暗色模式切换
- 响应式布局演示
- 交互效果预览（3D 按钮、动画等）

### 步骤 2: 首页布局重构 (index.html + style.css)

**修改文件**:
- `templates/index.html` — 重构 HTML 结构
- `static/style.css` — 更新首页相关样式

**具体改动**:
1. 导航栏整合：将主题切换和管理入口合并到顶部导航栏
2. 小组件重定位：从右侧浮动改为底部横排
3. 主卡片宽度调整：500px → 560px
4. 分区标题增加渐变装饰线
5. 作品网格增加 hover 动画
6. 文件列表项增加图标和下载动画

### 步骤 3: 管理后台布局重构 (admin.html + style.css)

**修改文件**:
- `templates/admin.html` — 重构 HTML 和 JS
- `static/style.css` — 更新管理后台样式

**具体改动**:

**修改文件**:

**具体改动**:
1. 添加 Logo 和品牌元素

### 步骤 5: AI 对话页优化 (chat.html + style.css)

**修改文件**:
- `templates/chat.html` — 增强交互

**具体改动**:
1. 欢迎区增加视觉效果
2. 消息增加时间戳
3. 输入区增加快捷提示词
4. 侧边栏优化

## 假设与决策

1. **保持纯 HTML/CSS/JS 技术栈** — 不引入前端框架，保持项目轻量
2. **保持现有 CSS 变量体系** — 在现有变量基础上扩展，不重写
3. **保持 Go 模板语法** — 原型页面是纯静态 HTML，实施时转为 Go 模板
4. **优先移动端体验** — 所有改动以移动端优先设计
5. **原型页面为独立文件** — 不影响现有功能，仅用于预览

---

## 验证步骤

1. 在浏览器中打开 `prototype.html`，检查 4 个页面的布局效果
2. 切换亮色/暗色模式，验证主题适配
3. 调整浏览器窗口大小，验证响应式布局
4. 确认所有交互效果（3D 按钮、动画、弹窗）正常
5. 确认原型与现有功能不冲突（独立文件）
