### 操作踩坑（下次直接照做）

- `docker run --rm ... ./linktree --rotate-admin-password` 是**常驻服务**，前台运行会一直挂着（本次导致线上短暂下线约 3 分钟）。
  必须加 `timeout 20` 或 `-d` 后再删容器。推荐流程见 `linktree/DEPLOY.md` 第 4 节。
- 从 Windows 管道给 `ssh "bash -s"` 传脚本时，CRLF 会被 bash 误判（`syntax error near unexpected token 'fi'`）：
  先 `scp` 脚本再 `sed -i 's/\r$//'`，或 `Get-Content -Raw` 后 `-replace "\`r",""`。
- 沙箱内 `go build` 需重定向缓存：`$env:GOCACHE="<工作区>\.dsh-tmp\gocache"`（默认 `%LocalAppData%\go-build` 被拒）。
- 沙箱内 `npm run build`（esbuild）会 `spawn EPERM`，须完整权限执行；脚本文件受执行策略限制，
  用 `& ([scriptblock]::Create((Get-Content ... -Raw)))` 绕过；Windows PowerShell 5.1 没有 `Invoke-WebRequest -Form`，上传用 Python。
- **Docker 缓存坑**：只上传 `web/src/*` 后 `docker compose up -d --build` 会命中旧的 `COPY web/ .` 层，
  前端不更新（线上仍是旧 `index-CkWfqCVc.js`）。前端源码变更必须 `docker build --target webbuilder --no-cache`。
